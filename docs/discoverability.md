## Implementation

- Keep one consistent product name, explicit independent-fork identity, maintained version and public source.
- README opens with a literal capability statement, not a vague promise.
- Bilingual FAQ answers concrete questions about missing images, local paths, title/cover preservation, permissions and publishing boundaries.
- Link usage, privacy, source attribution and versioned release notes so answers can be checked.
- GitHub topics: chrome-extension, markdown, x-articles, obsidian, local-first, article-import, browser-extension.
- Do not add unrelated model names, “best”, invented download counts, fake reviews or keyword lists to the store description.
- No automatic mass posting or backlink creation is authorized by this release.

## Measure after launch

Record actual repository traffic and store impressions/installations if available to the owner. Separate discovery, installation and successful import. Do not attribute growth to GEO without evidence; this release does not add user tracking.
