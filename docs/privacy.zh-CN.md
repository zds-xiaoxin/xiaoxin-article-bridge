# 隐私政策

产品：Xiaoxin Article Bridge（小新文章桥）。生效日期：2026-09-21。
维护者：GitHub 用户 labixiaoxins。[联系入口](https://github.com/labixiaoxins/xiaoxin-article-bridge/issues)，请勿公开提交私人文章、客户资料、Cookie 或令牌。

唯一用途是将用户选择的 Markdown 和配图导入 X Articles 草稿。插件读取选入的文章、文件以及相关 X 标签页地址和编辑器状态。草稿、设置、导入历史和诊断记录保存在本机 Chrome 扩展存储中。原有文件夹授权流程可能在 IndexedDB 保存目录句柄；新增整包导入的文件引用仅在当前侧栏会话中保留。

写入草稿时，文章和图片会发送给 X。插件使用浏览器已有 X 会话，不要求输入 X 密码，不向开发者发送登录信息。授权远程图片网站后，插件会请求该网站的图片；对方可获得 IP、请求地址等正常网络信息，图片请求不携带浏览器凭据。X 与图片网站分别适用其自身政策。

本版本没有开发者内容服务器、广告、数据出售或统计遥测。这不等于上传 X 时数据不会离开本机。诊断可能包含文章内容、地址和错误信息，分享前应自行检查脱敏。

本地记录保留至通过插件相应清理功能或删除扩展本地数据移除。移除前先导出需要的草稿；移除扩展不会删除已经保存到 X 的内容。关闭侧栏可结束整包选择会话。可在 Chrome 扩展设置中撤销可选网站权限。

storage 用于本地草稿及设置；sidePanel 用于侧栏；tabs 用于找到目标编辑页，不用于建立浏览画像；X/Twitter 页面脚本用于导入；可选 HTTP/HTTPS 权限仅用于用户批准的图片网站，不加载远程可执行代码。

数据只用于披露的文章导入用途，遵守 Chrome Web Store User Data Policy 及 Limited Use 要求，不用于出售、广告定向或无关画像。行为改变时须更新政策并取得必要同意。详见 [英文完整说明](privacy.md)。
