# 使用说明

从 Releases 下载 ZIP 并解压，在 chrome://extensions 开启开发者模式，点击“加载已解压的扩展程序”，选择包含 manifest.json 的目录。其他 xPoster 版本先停用，避免重复脚本。

侧栏“待发布”页顶部是文章卡片，步骤条为 **选文件夹 → 检查 → 预览 → 写入草稿**。

1. **选文件夹**：点击“选择文章文件夹”，选 article.md 和 assets 所在目录。选过一次后，下次打开侧栏会出现“继续上次的文件夹”。如果 Chrome 弹出读取权限确认，选择允许即可；拒绝后可再点一次重新授权。“忘记”会清除记住的文件夹。
2. **检查**：列表显示每处图片引用的状态（就绪、缺失、格式不支持、过大、远程）和大小。单张超过 5 MiB 或合计超过 24 MiB 时会自动在本机压缩，显示“压缩前 → 压缩后”。GIF 不压缩，过大时会提示你手动处理。改了正文后点“重新检查”。
3. **预览**：点“预览效果”，查看近似 X 长文样式的标题、封面、正文、图片和表格。勾选“用文章标题/封面替换 X 中的”会立即反映在预览里；默认不勾选，保留 X 草稿中已有的标题和封面。
4. **写入草稿**：点“去写入草稿”或底部“写入到 X 草稿”。看到检查通过只代表本地素材已找到，不代表 X 上传成功；写入后请到 X 页面检查。不会自动发布。

Obsidian 写法 `![[图片.png]]`、`![[图片.png|300]]` 可直接使用，会在同级目录、assets/ 以及文件夹内唯一同名文件中查找；宽度参数会被忽略。

X 文章权限需由账号自身具备。遇到问题请用一个小的公开示例到 Issues 反馈，不要上传私人文章、Cookie、令牌或整个浏览器配置。
