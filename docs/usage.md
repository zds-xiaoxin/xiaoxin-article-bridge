# Usage

Download the release ZIP, extract it, enable Developer mode at chrome://extensions, and select Load unpacked. Select the folder containing manifest.json. Disable other xPoster variants first to prevent duplicate editor scripts.

Choose an article directory containing article.md and assets. The report is local validation, not upload confirmation. Confirm title/cover options, write to a draft and inspect it. This extension never publishes automatically. X Articles access is a separate requirement managed by X.

For errors, provide a small synthetic reproduction to Issues, not your private article, cookies, tokens or full browser profile.
