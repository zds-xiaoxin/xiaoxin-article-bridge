# 小新文章桥 v1.2.0

Markdown 和本地配图一起导入 X Articles 草稿。先检查、压缩、预览，再由用户确认写入；不自动发布。

- 小新 IP 视觉：暖纸底、墨线、橙色按钮、20px 卡片与底部实色阴影，统一侧栏和诊断页。
- 全新文章/桥/星光图标（16/32/48/128px），附商店图标与 440×280 宣传图源文件。
- 诊断页跟随已保存主题和系统明暗变化；完善 320/360/420px 窄屏适配。
- 保留 v1.1 的目录记忆、本地图片压缩、写入前预览和 Obsidian 图片语法。

验证：`npm run verify`（36 项单元测试及 smoke）和 `npm run test:browser` 通过。24 组页面/宽度/主题布局检查通过，零页面运行错误。ZIP 内 46 个文件逐字节核对一致，排除测试配置与本地证据。

**仍待维护者本人在已登录 X 上验证真实草稿写入。** 离线测试不代表 X 已保存草稿。商店未提交，未上架。使用时先备份文章，检查所有图片和标题封面，测试草稿不要发布。

解压 ZIP，在 Chrome 扩展管理中开启开发者模式，选择“加载已解压的扩展程序”。不必清除已有浏览器或扩展数据。
